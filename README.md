 <h1>Note app</h1>

<p>This is a website for me to pratice code. This webiste make for user to create notes and manage their notes. </p>

## Installation

<p>User clone this github to your pc</p>

```bash
  git clone https://github.com/cthanh2204/Note-app.git
```
<p>After clone the github user install all the dependencies in client folder and server folder with command: </p>

```bash
  npm install
```
<p>After install all the dependencies, user now can run the code but remember you must start in both client and server</p>

- Run in client

```bash
  npm run dev
```
<hr></hr>

- Run in server

```bash
  npm run start
```
